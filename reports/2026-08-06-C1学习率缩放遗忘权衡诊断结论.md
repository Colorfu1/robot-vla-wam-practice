# 2026-08-06 C1 学习率缩放遗忘权衡诊断结论

## 重要进展

- C1 遗忘权衡诊断的两个变体均完成 30,000 步训练、6 个 checkpoint 的目标验证和 6 个 checkpoint 的完整背景 test。
- 变体 A 复现了正式 C1 的目标验证终点：step 30,000 为 59/60（98.3%）；6 个 checkpoint 的背景能力均为 0/210。
- 变体 B 将学习率从 `1e-4` 按 global batch 线性缩放到 `1.25e-5`，目标验证最佳点为 step 10,000：58/60（96.7%）。
- 变体 B 在 step 10,000 的背景 test 达到 55/210（26.2%），明显高于变体 A 的 0/210，但仍低于 B0 记录的 183/210。
- 变体 B 在 step 10,000 之后目标和背景成绩都下降，说明降 LR 带来的最佳权衡点位于早期 checkpoint，而不是训练终点。
- 本报告只登记诊断结论；变体 B 的 checkpoint 仍属于 `diagnostic_target_validation`，不替换正式 C1，也未进行正式 210 条目标协议评测。

## 实验目标与对照

本诊断回答：C1 的背景能力丢失，是否部分来自 global batch 从 B0 的 64 降到 C1 的 8 后仍沿用 `1e-4` 学习率；早停或按 batch 缩放学习率能否在保持目标任务能力的同时保留背景能力。

| 变体 | 学习率 | 训练步数 | 其他设置 |
|---|---:|---:|---|
| A `c1_a_same_config` | `1e-4` | 30,000 | global batch 8、BF16、8×1、seed 1000 |
| B `c1_b_scaled_lr` | `1.25e-5` | 30,000 | 其余设置与 A 完全相同 |

两者均从 selected B0 初始化；不引入背景数据回放、不使用 LoRA、不改变已发表的正式 C1。

## 诊断结论

1. **降 LR 能显著缓解背景遗忘，但不能恢复背景能力。** A 在 step 5,000 到 30,000 的背景成绩全部为 0/210；B 的背景成绩维持在 47–55/210，峰值出现在 step 10,000。
2. **最佳权衡点是 B step 10,000。** 此时目标 validation 为 96.7%，仅比 A 的最佳目标成绩低 1 条，同时背景从 0/210 提升到 55/210。
3. **训练过久会损害 B 的目标和背景能力。** B 在 step 10,000 后目标 SR 从 96.7% 降到 88.3%，背景 SR 从 26.2% 降到 22.4%，因此不能把 30,000 步终点当作 B 的代表点。
4. **学习率与 batch 不匹配是遗忘的一个贡献因素，但不是完整根因。** B 只恢复到 55/210，而 B0 的历史记录为 183/210；剩余差距说明仅调整优化步幅不足以恢复背景能力。后续 `c1_replay_k4` 将背景数据加入训练后达到 149/210，完整结果见 [C1 遗忘诊断与背景数据回放结论](2026-08-06-C1遗忘诊断与背景数据回放结论.md)。

## 结论边界与限制

- A/B 都是 `diagnostic` 运行；B 的 selected checkpoint 位于 `outputs/smolvla_libero/diagnostic/c1_b_scaled_lr/checkpoints/selected/`，selection set 为 `diagnostic_target_validation`。
- 本诊断没有测 held-out paraphrase 或 Prompt Swap，也没有正式跑 210 条 Canonical / Paraphrase / Prompt Swap 目标协议；不能把 B 的 58/60 解释成正式 test 成绩。
- B0 的 183/210 是既有文档记录，原始产物已丢失，本次未重跑；与 A/B 的 210 条结果只能作非配对参考。
- 只有一个 training seed 和一个缩放后学习率，不能据此声称对所有学习率或随机种子成立。
