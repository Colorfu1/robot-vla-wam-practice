# 2026-08-07 C3 改写增强 LoRA 正式评测结论

## 重要进展

- C3 完成 30,000 个 optimizer updates，六个 checkpoint 均生成；8 个 rank 的最终 instruction snapshot 共覆盖 240,000 次选择，canonical 实际比例为 25.024%，24 条 train paraphrase 全部被采样。
- 修正浮点数造成的 checkpoint tie 排序问题后，selected checkpoint 从 `025000` 更正为 `015000`：两者均为 57/60，`015000` 的 normalized offline action MSE 更低（0.383028 对 0.385061）。
- 当前 selected `015000` 的目标协议正式评测已完成 210/210 条 rollout：canonical 88/90，held-out paraphrase 67/90，Prompt Swap 首次达成 30/30。
- C3 相比 C2 的 held-out paraphrase 成功率从 19/90 提升到 67/90（+53.3 个百分点），三个目标任务均改善；canonical 从 87/90 提升到 88/90。
- 旧的 C3 background retention `0/210` 产物是在选模修正前通过可变的 `selected/` 路径生成的，不能归因到当前 `015000`；当前 winner 的 background test 仍待重跑。

## 实验范围与冻结条件

- Task suite：LIBERO-Goal 目标任务 1 / 4 / 8；Prompt Swap reference task 为 task 1，目标为 stove、cabinet、plate。
- Dataset：目标训练集 113 条 demonstration / 11,022 帧；offline validation 30 条 / 2,969 帧；闭环 validation 6 个 checkpoint × 3 任务 × 20 状态 = 360 条 rollout；最终 target protocol = 210 条 rollout。
- Observation keys：两路 256×256 RGB（`observation.images.image`、`observation.images.image2`）和 8 维 `observation.state`。
- Action space：7 维相对末端动作。
- Action horizon：模型 chunk size 50，实际执行 `n_action_steps=10`。
- Control frequency：10 Hz；每条正式 test episode 最多 300 steps。
- Policy：从 selected B0 `025000` 初始化，rank-32 LoRA，25% canonical + 75% train paraphrase，BF16，8×1 data-parallel layout，global batch 8，train seed 1000。
- Test policy seed：2000；目标 split、paraphrase 文件和 protocol 配置沿用冻结 SHA-256 绑定。

结果类别：训练为 `Formal / Offline`，checkpoint selection 为 `Formal / Closed-loop / Validation`，目标协议为 `Formal / Closed-loop / Test`。

首次达成混淆矩阵为完全对角：stove 10/10、cabinet 10/10、plate 10/10。所有 episode 都运行完整

## 与 C1/C2 的对照

| Model | Canonical | Held-out paraphrase | Para Gap | Prompt Swap 首次 / 终态 |
| --- | ---: | ---: | ---: | ---: |
| C1 Default Non-PEFT | 87/90 = 96.7% | 30/90 = 33.3% | 0.6333 | 29/30 / 27/30 |
| C2 Canonical LoRA | 87/90 = 96.7% | 19/90 = 21.1% | 0.7556 | 28/30 / 28/30 |
| **C3 LoRA + Paraphrase** | **88/90 = 97.8%** | **67/90 = 74.4%** | **0.2333** | **30/30 / 29/30** |

相对 C2，C3 的 held-out paraphrase 提升 48/90 个 case，即 +53.3 个百分点；按相同 task/init-state
对齐后的 paired bootstrap（10,000 次，seed 1000）95% 区间为 `[0.4111, 0.6444]`。Canonical 的点估计
只提升 1.1 个百分点，paired bootstrap 95% 区间为 `[-0.0333, 0.0556]`，因此不能宣称 C3 在 canonical
上显著优于 C2。

C3 的 `para_gap` 为 0.2333，bootstrap 95% CI `[0.1444, 0.3333]`，显著小于 C1 的 0.6333 和
C2 的 0.7556。三个目标任务的 held-out paraphrase 都比 C2 高：task 1 为 21/30 对 7/30，task 4
为 27/30 对 8/30，task 8 为 19/30 对 4/30。

## 训练与采样审计

- Train loss：step 1 为 0.156775；selected step 15,000 前 1,000 步均值为 0.073442；最后 1,000 步均值为 0.070925；step 30,000 最后记录为 0.066038。
- Grad norm：全程峰值 0.662；学习率峰值 `9.990e-5`，step 30,000 为 `2.5e-6`。
- Trainable parameters：1,485,312 / 451,531,488（0.329%）；selected adapter 文件约 5.68 MiB。
- GPU memory：各 rank 记录的 peak allocated 约 1.68 GiB、peak reserved 约 1.95 GiB。
- Instruction sampling：8 个 rank × 30,000 selections = 240,000；canonical 60,058 次（25.024%），train paraphrase 179,942 次（74.976%）；24 条 train paraphrase 均被采样，task 总量分别为 79,753 / 80,210 / 80,037。
- 训练 artifact 的一个限制：所有 `runtime_attempt_000_rank_*` 最终状态都记录为 `failed`，错误为 teardown 阶段的 `Default process group has not been initialized`。但 `train_metrics.jsonl` 已完整记录到 step 30,000，六个 checkpoint 均完整，selected adapter 也已成功加载并通过闭环评测。因此训练计算结果可用，但 launcher 的进程组清理状态仍应作为实现问题单独修复，不能把 runtime manifest 写成 clean success。

## 延迟与失败案例

21 个 target protocol job 的 job-level 平均模型查询延迟为 p50 `331.6 ms`、p95 `479.5 ms`；平均 action TV
为 `0.0392`，平均 action jerk 为 `0.0496`，平均 gripper toggle 为 `3.72`。

- Canonical：2 条 `time_limit`，分别出现在 task 4 的 state 0 和 task 8 的 state 44。
- Held-out paraphrase：23 条 `time_limit`；主要集中在 task 1 的 prompt 0（6/6 失败）和 task 8 的 prompt 1（5/6 失败）。
- Prompt Swap：首次达成无失败；1 条 plate episode 只在 terminal hold 阶段丢失目标。
- Background retention：当前 selected `015000` 尚未重跑；8 月 5 日的旧 `c3_selected` `0/210` 只记录了可变 selected 路径，且早于选模修正，排除在本结论之外。

## 结论边界与下一步

本实验支持：

- 25% canonical + 75% train paraphrase 的 LoRA 训练显著改善了 held-out paraphrase 泛化；C3 满足当前 paraphrase pilot 的晋级信号。
- C3 没有牺牲 canonical 目标任务能力；C3 与 C2 的 canonical 结果在统计上没有可确认差异。
- C3 的 Prompt Swap 首次目标服从达到 100%，且三目标混淆矩阵完全对角；当前主要剩余问题是少数改写句的语言敏感性和终态保持。

本实验不支持：

- C3 在所有语言表达上都已鲁棒；task 1 prompt 0 与 task 8 prompt 1 仍明显偏弱。
- C3 已经保住 background 能力；当前 winner 的 background retention 尚未有有效测量。
- 单个 training seed 下的跨随机性结论；需要额外 seed 和未查看的新初始状态才能扩大结论范围。

下一步是使用当前 `015000` selected checkpoint 重跑 background retention test；在此之前，不引用旧的
`c3_selected 0/210` 作为 C3 正式结论。
