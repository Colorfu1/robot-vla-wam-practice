## 已完成实现

原型 pipeline 从 E0 完整轨迹构造物体中心化 8-token sketch，用自定义 component
distance、K-medoids、多初始化和 100 次 80% subsample 检查稳定性。原始 dataset 不被
改写；episode assignment 单独保存在 sidecar。

两个条件模型都把单个离散 embedding 拼入现有 observation global condition。未来
prototype sketch 不进入模型，ID 在整个闭环 episode 中固定。Mode-BCChunk 与
Mode-Diffusion 使用逐 tensor 相同的 step-zero 参数。

闭环输出同时报告 task success、classifiable、prototype adherence、controlled success
和 NULL mode support。每条 rollout 使用与 train prototype 相同的图像几何、sketch、
distance scales 和 q95 rejection radius。

## 实验字段

- Task suite：PushT
- Dataset size：206 episodes；prototype fit/train 使用 165 train episodes
- Observation keys：96×96 RGB、二维 agent position；历史长度 2
- Action space：二维绝对 target position
- Action horizon：内部 16；执行 `[1:9]` 共 8 actions
- Control frequency：10 Hz
- Train loss：当前仅有 1-step Smoke；正式 loss 未测
- Open-loop action error：未正式测量
- Closed-loop success rate：未正式测量
- Latency：只验证 runtime 记录链路；DDPM100 正式 latency 未测
- Failure cases：一帧 Smoke 无法形成稳定接触，所有 sketch 均不可分类；这不是能力结果

## 限制

条件控制成功只能证明模型能使用 Prototype ID，不能自动证明原无条件模型已学习完整
混合分布。NULL 分支必须在同一环境由多个 seeds 产生至少两个满足门槛的成功 prototype，
才能支持该 E5 checkpoint 的多成功模式覆盖。

现有 demonstrations 没有严格配对的“相同初始 observation、不同 prototype、不同成功
action”监督，因此正式 E5 仍是全局 prototype 条件控制和组合泛化实验，不是严格同状态
多解的最终证明。
