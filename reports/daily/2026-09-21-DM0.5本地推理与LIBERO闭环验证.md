## 模型研究与本地选择

DM0.5 是 Dexmal 的 VLA，公开实现使用 Gemma3 视觉语言骨干与动作专家，通过
flow matching 学习动作。模型名称中的 0.5 不是参数量。
本次 safetensors 中存储约 58.29 亿个 BF16 参数，文件约 11.66GB；文件大小、
内部数据偏移、下载 revision 和 SHA-256 校验均通过。

选用官方已适配 LIBERO 的 checkpoint，避免把基础模型的双臂控制协议直接接到
Franka 仿真。推理进程使用独立 Python 3.10 / PyTorch 2.11.0+cu128 /
Transformers 5.3.0 环境，仿真复用 robot-practice 与现有离线资产。
当前采用默认 PyTorch 后端，视觉 SDPA、语言 eager、动作 SDPA、BF16，关闭 Liger。
源码、权重 revision 与完整命令见[实验指南](../guides/dm05/README.md)。

来源：[官方源码](https://github.com/dexmal/opendm/tree/fbab441b63c789e5c37f7293e61fea9ed356c6c5)、
[LIBERO checkpoint](https://huggingface.co/Dexmal/DM05-libero/tree/25a8e0d38a8eaeaae41a44d7b4a2378fd8ce1088)。

| Latency | 首次 1052.5ms；第二次 469.1ms；后 3 次平均 328.6ms | 平均 HTTP 443.8ms，包含首次请求，无单独预热 |
| Failure cases | 首轮 FA2 初始化缺包；本地入口修复后 5/5 通过 | 此 episode 未出现失败；尚无系统失败类型统计 |

闭环沿用官方图像双轴翻转、8D 状态排列与连续夹爪设置。先静置 10 步，再按
spatial 最多 220 步执行；此次在第 77 步收到成功信号。该 episode 没有缩短
官方步数上限，但抽样规模只有一个任务、一个初始状态，因此仍标为 Smoke。

上述 11.13GiB 是模型进程由 PyTorch 统计的峰值分配量，不是整卡总占用，
也不包含仿真进程和其他已有进程。合成输入时延不代表所有任务与指令长度的时延。

## 架构形状核验补充（Smoke）

已完成[详细架构说明](../guides/dm05/01_dm05_model_architecture.md)和可复现形状探针。
真实权重推理前缀为 `[1,564]`，训练 collator 补齐到 `[1,1024]`；两张图经视觉编码器
分别生成 256 个 2560D token，34 层前缀 K/V 对接 34 层 1024D 动作专家。
内部动作是 `[1,10,32]`，对外裁为 7D；LIBERO 当前 `add_state=False`。

推理前向与 train-mode / no_grad 的训练前向均完成，后者返回有限标量 loss；
未执行 backward 或 optimizer step，不能据此声称训练已跑通。
参数存储核验确认 embedding 与 lm_head 未绑定，完整加载参数数目为 5,829,112,208。
仅记录 shape/dtype/计数，产物为 `outputs/dm05/architecture/shapes.json`。
