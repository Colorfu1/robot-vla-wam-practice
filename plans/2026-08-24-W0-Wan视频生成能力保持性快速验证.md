### 2. 准备 `VBench-I2V-mini-21` 并固定推理协议

选 VBench-I2V，因为它有公开的 I2V 图像/prompt suite 和可复现实现，且官方
sampling records 包含 Wan2.1-I2V-14B 与 Wan2.2-TI2V-5B。本计划在看到两个
checkpoint 结果前按下列规则固定 **21 prompts / 15 unique images**：

1. `subject-7`：从 `i2v_subject` 的 7 个 `image_type` 各取 1 条：`animal`、
   `food`、`multiple-human`、`other`、`plant`、`single-human`、`transportation`。
2. `background-7`：从 `i2v_background` 按 `abstract:1, architecture:2, indoor:2,
   scenery:2` 取 7 条，覆盖全部 4 个 background type。
3. 类内候选用
   `SHA256("20260824\n" + image_type + "\n" + image_name + "\n" + prompt_en)` 升序取前
   `quota` 条；不许手工挑图。
4. `camera-motion-7`：从未进入 `background-7` 的 background image 中取上述 hash
   最小的 1 张，分别搭配 `pans left/right`、`tilts up/down`、`zooms in/out`、
   `static` 七条官方指令。
5. 每条只生成 1 个视频，seed 固定为 `52000 + global_index`。因此每 checkpoint
   21 条，合计 42 条；这不等同于 VBench 完整协议的每 prompt 5 次采样。

推理协议由一次性 `check-protocol` 决定，两 checkpoint 必须共用一种协议：

- 若两者 video-expert state dict 都能对 pinned Wan2.2 TI2V-5B DiT 做 strict load，且
  单条 smoke 成功，选 `wan22-ti2v-compatible`：`1280x720`、81 帧、16 fps，使用
  pinned Wan2.2 TI2V 采样器。
- 只要任一 checkpoint 不兼容，两者统一选 `fastwam-native`：`448x224`、9 帧、
  16 fps、10-step `infer_joint`，`action=None`、`proprio=None`。输入图先中心裁剪到
  2:1 再 resize，评估时使用这张实际 conditioning image。

### 4. 构建 `W0-Video-40` 并比较命令条件生成

从现有四个 FastWAM LIBERO `_no_noops_lerobot` 数据集中，每个 suite 的 10 个 task
各选 1 个 clip，共 **40 clips / 40 tasks / 4 suites**。不看模型结果，固定：

1. 候选窗口为同 episode 内连续 33 个 raw step，不跨 episode、不 padding。
2. 取 `[0,4,8,...,32]` 共 9 帧；第 0 帧是 conditioning frame，后 8 帧是 GT。
3. front/wrist 分别缩至 `64x64` 计算相邻帧 absolute pixel difference，两 camera 等权
   平均为 `motion_score`。每 task 选最接近其候选分布 p75 的窗口；并列时按
   `episode_index,start_frame` 升序取第一个。
4. suite 顺序固定为 `spatial,object,goal,10`，task 顺序为 `0..9`；样本 seed 为
   `42000 + global_task_index`。
5. 两个 checkpoint 都只接收拼接的 front/wrist 首帧和该 task 的原始 language
   command，固定 9 帧、10-step FastWAM 原生生成。

```bash
bash scripts/experiments/literature/run_w0_video_generation_eval.sh \
  --mode=prepare-w0 \
  --dataset-root=pretrained/w0_fastwam/dataset/data/libero_mujoco3.3.2 \
  --suites=libero_spatial,libero_object,libero_goal,libero_10 \
  --selection=one-per-task-motion-p75 \
  --raw-frames=33 --video-stride=4 --base-seed=42000 \
  --output=outputs/literature/w0_fastwam/video_generation/w0_video_40/manifest.json
for variant in fw_fz fw_v; do
  if [ "${variant}" = fw_fz ]; then
    checkpoint=outputs/literature/w0_fastwam/causal_10ep_frozen/no_video/checkpoints/weights/step_021700.pt
  else
    checkpoint=outputs/literature/w0_fastwam/causal_10ep/with_video/checkpoints/weights/step_021700.pt
  fi
  bash scripts/experiments/literature/run_w0_video_generation_eval.sh \
    --mode=generate --dataset=w0-video-40 --variant=${variant} \
    --checkpoint=${checkpoint} \
    --manifest=outputs/literature/w0_fastwam/video_generation/w0_video_40/manifest.json \
    --output-root=outputs/literature/w0_fastwam/video_generation/w0_video_40/${variant}
  bash scripts/experiments/literature/run_w0_video_generation_eval.sh \
    --mode=score --dataset=w0-video-40 --variant=${variant} \
    --manifest=outputs/literature/w0_fastwam/video_generation/w0_video_40/manifest.json \
    --videos=outputs/literature/w0_fastwam/video_generation/w0_video_40/${variant}/videos \
    --output=outputs/literature/w0_fastwam/video_generation/w0_video_40/${variant}/metrics.json
done
```

W0 指标只算后 8 个 future frame；先将 `224x448` 拼接图拆成两个 `224x224`
camera，对帧和 camera 取平均，再分别输出 per-task、per-suite 和 4-suite macro：

- PSNR：越高越好。
- SSIM：越高越好。
- LPIPS：越低越好；实现固定 `lpips==0.1.4` 和 evaluator 权重 hash。

可视化不挑样本：每 task 生成 `conditioning | GT | FW-FZ | FW-V` 四联视频，再为每个
suite 生成包含全部 10 个 task 的固定 montage。

## 判断标准

| 检查项 | 通过标准 | 不满足时 |
| --- | --- | --- |
| 外部集固定 | 21 prompts / 15 images，三组各 7，七种 camera motion 各 1，manifest 可重建 | 停止，不生成 |
| 外部生成 | `FW-V` / `FW-FZ` 各 21/21，无缺帧、空视频、NaN，且协议与 seed 逐条一致 | 修复后重跑受影响 variant，不比较未配对结果 |
| VBench 指标 | 两者都完整输出 9 项 dimension score 及差值 | 不得用部分指标宣称通用视频能力保持 |
| W0 集固定 | 恰好 40 task，每 suite 10，每 task 1，全部 9 帧且无 padding | 停止，不生成 |
| W0 生成与指标 | 两者各 40/40，输出全部 per-task/per-suite/macro PSNR、SSIM、LPIPS | 不得只用 montage 下结论 |
| W0 固定视觉对比 | 40 个四联视频与 4 个 suite montage 全部存在，无人工挑样本 | 补齐后再做定性比较 |
| 结论口径 | 分别报告外部 9 项与 W0 3 项差值；混合结果写「指标分化」 | 不设任意阈值，不将小样本差值包装为显著结论 |

本计划的「完成」指两条评测都得到完整、配对、可溯源的指标与固定视频，
不预设 `FW-V` 必须胜过 `FW-FZ` 才算执行成功。

## 风险与停止条件

- `VBench-I2V-mini-21` 每 prompt 只有 1 个 seed，只用于低成本发现明显差异。不得将其称为
  完整 VBench、Wan-Bench 2.0 或官方 Wan2.1/Wan2.2 分数。
- 若 strict load 或 81 帧 smoke 失败，不修改 checkpoint 来强行适配；按预定规则让两组
  统一回退 `fastwam-native`，并在结果中标明「VBench-I2V 数据/指标上的
  FastWAM-native 相对评测」。
- `W0-Video-40` 从 1,712 条训练 demonstration 中取样，不是 held-out split；只能
  表明 W0 训练分布内的生成匹配情况。
- 当前 `action_conditioned=false`。若实现传入 GT action/proprio，或报告宣称验证了
  action-conditioned generation，停止并修正口径。
- 两个 variant 的 manifest、seed、帧数、分辨率、推理步数、VAE/text encoder 或
  evaluator 权重不一致时停止比较。
- 任一 checkpoint、数据、VBench image suite 或 evaluator 权重不完整时停止；不在评测中途
  替换样本、调整 seed 或只重跑不好看的视频。
- 不提交数据、权重、生成视频、指标 cache 或日志；最终实验记录单独写入
  `reports/`，本 plan 不承载结果。
