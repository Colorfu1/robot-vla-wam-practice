### 1. 加入目标块角常量

```python
PUSHT_GOAL_BLOCK_ANGLE_RAD = math.pi / 4.0  # gym_pusht goal_pose = [256, 256, pi/4]
```

不要在别处再硬编码 `math.pi / 4`。

### 2. 修正旋转误差参考角

改 `src/robot_practice/experiments/pusht_diffusion/route_field_episodes.py`
（`achieved_route_metrics`，约第 501 行）：

```python
"final_rotation_error_deg": (
    float(abs(wrapped_angle_difference(final_angle, PUSHT_GOAL_BLOCK_ANGLE_RAD)) * 180.0 / np.pi)
    if np.isfinite(final_angle)
    else None
),
"goal_block_angle_rad": PUSHT_GOAL_BLOCK_ANGLE_RAD,
```

新增 `goal_block_angle_rad` 列是为了让每份产物自带参考角、可与旧产物区分。
`route_field_checkpoint_selection.py:174` 复用同一函数，自动一起修正。

### 3. 补齐服从度的可判定性计数

改 `src/robot_practice/experiments/pusht_diffusion/route_field_eval.py`
（`_paired_condition_rows`，约第 1165 行），在**保留** `obeyed_count` / `obeyed_rate`
原定义不变的前提下追加：

| 新列 | 定义 |
| --- | --- |
| `undecidable_pair_count` | `commanded_minus_oracle_adherence == 0` 的配对数 |
| `decidable_pair_count` | 差值非 0 的配对数 |
| `obeyed_count_decidable` | 可判定配对中差值 > 0 的数量 |
| `obeyed_rate_decidable` | `obeyed_count_decidable / decidable_pair_count`，分母为 0 时为 `None` |
| `obeyed_wilson95_low_decidable` / `..._high_decidable` | 对可判定子集的 Wilson 区间 |
| `two_cell_probe_count` | `requested_route_length == 2` 的探针数 |

`two_cell_probe_count` 单独列出，因为 `[a,b] → [b,a]` 时 LCS 对 commanded 与 oracle
都只能匹配 1 格，差值被结构性钉死在 0；而真正服从所需的 `a→b→a` 又会被
`simplify_macro_route` 当回头路删除。这类配对无法承载服从度证据。

**新列只作诊断，不替换原判据。** 原计划
[2026-08-03 RF7 正式训练与条件遵循评测](2026-08-03-RF7正式训练与条件遵循评测.md)
冻结的判据是 `obeyed_rate > 0.5` 且 Wilson 下界 > 0.5，已经以 0/19 判负；新列只会**削弱**
该负结论的强度，不可能把它翻成正结论，因此不构成"看到数字后改判据"。

以下问题在审计中已确认存在，但都需要改指标定义或重跑 rollout，必须另起计划：

- `commanded_first_segment_progress_cells` 用整段 300 步净位移投影，并非"首段"读数。

- **不得触碰原始 audit 目录。** 原计划已冻结"audit 只跑一次"；本计划是对同一批 rollout

  重导出产物需如实标注该字段缺失，不得伪造。
